moreland — turn a USB-connected Android tablet into a second monitor

USAGE
    moreland [OPTIONS]

    With no options it runs as a daemon: plug the tablet in and a virtual
    monitor appears, unplug it and the monitor disappears.

OPTIONS
    --max-width <PX>    cap on auto-detected width     [default: 1920]
    --native            stream the tablet's full panel resolution
    --width <PX>        pin width  (requires --height)
    --height <PX>       pin height (requires --width)
    --fps <N>           virtual output refresh rate    [default: 90;
                        60 on KDE, where 90 can stutter]
                        120 measures better still; 144 saturates
    --bitrate <KBPS>    H.264 target bitrate           [default: 20000;
                        60000 on KDE, where encoding is NVENC/x264]
    --side <EDGE>       which edge of the main screen the tablet sits against:
                        right, left, above or below       [default: right]
                        (KDE reads your live layout; other compositors
                        use the fixed position below)
    --position <X>      exact x of the virtual output; overrides --side
    --position-y <Y>    exact y of the virtual output; overrides --side
                        without --side, the other compositors default to
                        x 0, y 1080: below a primary no taller than 1080px
    --transform <N>     output rotation, 0-7 as in Hyprland [default: 0]
                        1 = 90 deg clockwise, i.e. a tablet on its side
                        applied with wlr-randr on labwc, which has no
                        monitor rule of the daemon's to carry it
    --output-name <NAME>
                        name of the virtual output      [default: moreland]
                        required on labwc, which cannot create one and must
                        be pointed at an existing headless output
    --print-rule        print the compositor configuration for the current
                        options, then exit: the `monitor=` line for
                        hyprland.conf and the `hl.monitor` call for
                        hyprland.lua
    --show-cursor       composite the mouse cursor into the stream
                        [default: on for KDE, off elsewhere]
    --hide-cursor       leave the cursor out of the stream
    --no-palm-rejection
                        let fingers through while the pen is in range
                        (KDE: touch and pen are forwarded from the tablet)

    --once              stream one session, then exit
    --seconds <N>       stop after N seconds (implies --once and --stats)
    --stats             print round-trip latency statistics on exit
    -h, --help          show this help

NOTES
    The tablet needs the companion app installed and USB debugging enabled.
    Diagnostics from the device:  adb logcat -s Moreland

    Resolution is detected from the tablet's panel and matched to its aspect
    ratio, capped at --max-width. Pass --width and --height together to pin it.
    Rotation does not change the stream size: --max-width caps the panel mode,
    so a quarter-turned output streams the same pixels, just upright.
